# JulogicIDE

> Um IDE moderno para desenvolvimento Android, criado para funcionar diretamente em dispositivos Android.

O **JulogicIDE** é um projeto **Open Source** que tem como objetivo construir um ambiente de desenvolvimento Android completo para smartphones e tablets.

A proposta é oferecer uma experiência moderna e produtiva, permitindo criar, editar, compilar, depurar e gerenciar aplicações Android reais utilizando **Gradle**, **Kotlin**, **Java** e outras ferramentas essenciais, tudo diretamente no dispositivo móvel.

---

## 🚧 Status do Projeto

> **O JulogicIDE ainda está em desenvolvimento inicial.**

Neste momento, o projeto encontra-se em fase de arquitetura, implementação da interface e desenvolvimento dos módulos principais.

Grande parte dos recursos descritos neste documento representam o planejamento e a visão de longo prazo do projeto.

Acompanhe o progresso através das **Issues**, **Pull Requests** e **Roadmap**.

---

# 🎯 Nossa Visão

Queremos tornar possível desenvolver aplicações Android profissionais em qualquer lugar, diretamente de um smartphone ou tablet.

O JulogicIDE pretende unir praticidade, desempenho e uma arquitetura moderna para oferecer uma experiência comparável às principais IDEs desktop, mantendo uma interface otimizada para dispositivos móveis.

Nosso foco é construir uma plataforma aberta, extensível e orientada à comunidade.
