# AndroJuka

> Um IDE moderno para desenvolvimento Android diretamente no seu dispositivo Android.

O **AndroJuka** permite criar, editar, compilar, depurar e gerenciar projetos Android reais utilizando **Gradle**, **Kotlin**, **Java** e diversas ferramentas integradas, tudo sem precisar de um computador.

# 🚀 Instalação

Baixe a versão mais recente na página de **Releases**.

Após instalar o aplicativo:

1. Instale o JDK
2. Instale o Android SDK
3. Instale o Build Tools
4. Crie seu primeiro projeto

O próprio AndroJuka fará o download das ferramentas necessárias.
