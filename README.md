# JulogicIDE

> Um IDE moderno para desenvolvimento Android diretamente no seu dispositivo Android.

O **JulogicIDE** é um Ambiente de Desenvolvimento Integrado (IDE) desenvolvido para dispositivos Android. Ele permite criar, editar, compilar, depurar e gerenciar aplicações Android reais utilizando Gradle, Kotlin, Java e diversas ferramentas integradas, tudo sem precisar de um computador.

O projeto tem como objetivo oferecer uma experiência profissional de desenvolvimento mobile, reunindo em um único aplicativo editor de código, terminal, sistema de build, integração com Git, gerenciamento de SDKs, ferramentas Android e uma arquitetura extensível por plugins.

---

## ✨ Recursos

- Editor de código para Kotlin, Java, XML e Gradle Kotlin DSL
- Terminal Linux integrado
- Sistema de Build com Gradle
- Gerenciador de Projetos
- Explorador de Arquivos
- Logcat
- Painel de Build
- Diagnóstico do IDE
- Gerenciador de SDK
- Gerenciador de JDK
- Integração com Git
- Marketplace de Plugins *(planejado)*
- Assistente de IA *(Pro)*
- Sincronização em Nuvem *(Pro)*

---

## 🚀 Objetivo

O JulogicIDE busca oferecer uma experiência semelhante à de IDEs como Android Studio e VS Code, adaptada para dispositivos móveis, permitindo que desenvolvedores criem aplicações Android profissionais diretamente do smartphone ou tablet.

---

## 📦 Ecossistema

O projeto será organizado em múltiplos repositórios oficiais:

| Repositório | Descrição |
|-------------|-----------|
| JulogicIDE | Código-fonte principal do IDE |
| JulogicIDE-Binaries | JDK, Android SDK, Build Tools e dependências |
| JulogicIDE-Templates | Templates oficiais de projetos |
| JulogicIDE-Plugins | Plugins oficiais |
| JulogicIDE-Docs | Documentação |
| JulogicIDE-Website | Site oficial |
